# MARCUUS — téléchargements

App Mac de montage : transcription, SRT Fixer, B-roll, palettes.

**➜ [Télécharger la dernière version](https://github.com/Masonnigg/marcuus-releases/releases/latest)**

- Mac avec puce Apple (M1, M2, M3, M4…) : `MARCUUS-…-arm64.dmg`
- Mac Intel : `MARCUUS-…-x64.dmg` (sans l'onglet Transcrire)

## Installer
1. Ouvre le `.dmg` et glisse **MARCUUS** dans **Applications**.
2. Première ouverture : double-clique, clique « Terminé », puis va dans
   **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**. Une seule fois.

## Mises à jour
MARCUUS vérifie les nouvelles versions à chaque ouverture. Quand une version sort, l'app demande
de se mettre à jour : un clic sur **Mettre à jour**, elle se télécharge et redémarre toute seule.
Tes réglages, palettes et transcriptions sont conservés.

`latest.json` est lu par l'app pour savoir quelle est la dernière version : ne pas le modifier à la main.
